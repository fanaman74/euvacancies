# Design — EU Employment vacancy register

The interface adapts the supplied MSOIT site: near-black surfaces, warm white text, vivid orange accents, Instrument Serif display type, Inter body text and JetBrains Mono metadata. Typefaces are served locally from `public/reference-fonts/`.

The home page uses a sticky navigation, a large serif hero and an interactive Europe map, followed by an orange register summary strip. The register retains its search, category, location, status and sorting controls, its responsive vacancy table and direct source links. Latest roles and method notes use restrained dark panels with fine borders. Orange identifies primary actions and selected states.

Keep the vacancy data, source attribution, independent status and application links accurate. Preserve keyboard access, visible focus, reduced motion and responsive layouts when extending the interface. The base styles remain in `public/styles.css`; `public/reference-theme.css` holds the reference-inspired theme.
